The five specifications were preserved byte-for-byte from the inputs used to
create these snapshots. Generated receipts, browser logs and duplicate renders
are disposable. Future intermediate renders belong in the ignored `.archify/`
directory; publish the selected HTML and specification together here.

for the current one-shot generation behavior and test commands.
