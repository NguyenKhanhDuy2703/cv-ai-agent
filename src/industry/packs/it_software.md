# Industry Pack: Information Technology & Software Engineering (IT)

## Core Technical Keywords & Competencies
- Architecture: Microservices, Event-Driven Architecture, Distributed Systems, Monolith-to-Microservices Migration.
- Cloud & DevOps: Docker, Kubernetes, CI/CD (GitHub Actions, GitLab CI), AWS (ECS, EKS, Lambda, S3), GCP, Terraform.
- Data & Storage: PostgreSQL, MySQL, Redis Caching, RabbitMQ, Kafka, Database Index Tuning, Query Optimization.
- Practices: Test-Driven Development (TDD), Domain-Driven Design (DDD), Clean Architecture, API Design (REST, gRPC).

## High-Impact Action Verbs
- English: Architected, Engineered, Designed, Optimized, Refactored, Deployed, Automated, Scaled, Streamlined, Spearheaded.
- Vietnamese: Thiết kế, Xây dựng, Tối ưu hóa, Tái cấu trúc, Triển khai, Tự động hóa, Vận hành, Mở rộng quy mô, Chủ trì.

## STAR Phrasing Recommendations
- Situation/Task: State system complexity, legacy bottlenecks, or high traffic demands.
- Action: Emphasize engineering best practices, design patterns, and tools used.
- Result: Highlight quantifiable improvements (e.g. latency reduced by X%, throughput increased to Y req/s, 99.99% uptime).
